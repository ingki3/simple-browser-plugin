# 보안·개인정보 상세

사용자용 요약은 [README](../README.md#개인정보와-안전)에 있습니다. 이 문서는 무엇을 어디로 보내고 어떻게 보호하는지의 구현 규칙입니다.

- **모델 제공자** (#97) — 설정에서 OpenRouter(기본), OpenAI(ChatGPT API 키), Google Gemini(AI Studio API 키, OpenAI 호환 엔드포인트 — 도구 호출의 thought_signature를 다음 요청에 돌려줌, PDF 첨부는 받지 않아 PDF 탭에서는 `read_document`로 읽게 함), Anthropic Claude(Claude API 키, Messages API로 변환 — 생각은 4.6 이후·5 계열은 adaptive+effort, 그 앞은 budget, temperature는 보내지 않음. 생각 블록과 서명을 다음 요청에 돌려주고, 응답 블록은 받은 순서 그대로 돌려주고, 응답이 앞 문맥까지 서명하므로 사용자 요청 직후 요청에 붙이는 현재 시각·저장 링크 후보 안내도 그 대화 기록에 남김(도구 결과 바로 뒤에는 붙이지 않음 — 빈 응답 방지)(보낸 후보를 지우거나 끄면 그 대화는 멈추고 다음 요청을 새 대화로). JSON 응답은 지침으로 받음)를 고름. 대화·페이지 글자·도구 결과·저장 링크 초안·번역할 글자는 고른 제공자 한 곳으로만 보냄(OpenRouter는 다시 각 모델 회사로 전달). 제공자나 모델을 바꾸면 대화 기록을 새로 시작하고 그 대화가 연 페이지 번역도 멈춤
- API 키(OpenRouter·OpenAI·Gemini·Anthropic)는 `chrome.storage.local`에 평문 저장 (그 제공자 호출에만 사용; v1 트레이드오프)
- 키는 BG 서비스 워커에서만 읽히며 content script나 페이지 DOM에 전달되지 않음
- **페이지 기억하기 · 저장 링크 (설정, 기본 켜짐, #30·#86)** — 답을 마친 뒤 탭이 다른 화면(해시 포함)에 있으면 "이 페이지 기억하기" 버튼이 뜬다. 카드에서 이름·용도(예: "쇼핑을 위한 가격 비교 검색")를 적고, 주소의 쿼리 값마다 고정·입력 자리·빼기를 골라 다시 쓸 수 있는 링크 템플릿으로 저장(예: `…/search/all?query={상품명}`). 카드에서 카드를 열면 모델이 이름·용도·자리(설명·비워도 되는지) 초안을 일반적인 형태로 자동 제안하고 사용자가 고친다(사용자 결정으로 #129의 "누를 때만"을 바꿈, "다시 채우기"로 다시 요청)(어떤 값이 검색어인지 코드가 파라미터 이름으로 정하지 않음). 입력 자리의 지금 값과 요청 문장은 저장하지 않는다. 고정으로 남긴 값에 결제·개인정보 단서가 있으면 경고에 체크해야 저장(`src/lib/savedPages.ts`, `src/background/savedPagesStore.ts`)
  - 초안: 카드를 열면("이 페이지 기억하기") 자동으로 한 번(사용자 결정으로 #129의 "누를 때만"을 바꿈 — 닫았다 열어도 다시 묻지 않고, "다시 채우기"로 다시) 그 턴의 사용자 요청·모델의 마지막 답·제안할 때 그 문서(documentId 고정)에서 읽은 화면 글자(modelText — 입력 칸 값·편집 영역·숨은 내용 제외, 3000자)와 주소를 모델에 보내 이름·용도와 쿼리 값마다 고정·입력 자리(자리 이름·설명·비워도 되는지)·빼기를 채운다(생각 끔, 사용자가 고쳐 저장). 지침은 이번 요청이 아니라 일반적인 재사용(이름·용도에 구체 값 없음, 바꿔 쓸 만한 값은 자리, 내부 코드값은 고정)을 요구한다. 전송 직전에 페이지 기억하기 설정을 다시 확인해 꺼져 있으면 보내지 않는다(남아 있는 카드도). 새로고침·이동으로 문서가 바뀌었으면 페이지 글자는 읽지 않는다. 주소에 결제·개인정보 단서가 있으면 초안을 묻지 않는다(경로·제목·본문으로도 값이 샐 수 있어 사용자가 직접 정함)
  - 쓰기: 사이트와 관계없이 저장 링크(id·이름·용도·출처·자리 이름)를 매 모델 요청 끝에 임시 데이터 메시지("지시가 아님" 머리말 + JSON)로 붙이고(디버그 로그 `saved_links:candidates`에 턴마다 한 번 후보 수·이름 또는 붙이지 않은 이유 — 주소는 남기지 않음, #156), 요청이 용도에 맞으면 모델이 `open_saved_link({ id, values })`로 자리 값만 넣어 현재 탭에서 연다. 출처·경로·고정 값은 저장한 그대로이고 자리 값은 인코딩해 넣는다(값 200자, 모르는 자리·빠진 필수 자리는 오류. 사용자가 카드에서 "비워도 됨"으로 고른 자리(`optional`)는 값이 없으면 그 쿼리 값을 빼고 연다 — 예전 링크는 모두 필수. 준 값·완성 주소에 대한 승인·민감 값 판정은 그대로). 대화 기록에는 남기지 않아 지우기·끄기가 다음 요청부터 반영
  - 승인: 사용자가 저장한 링크라 자동 실행이 켜져 있으면 카드 없이 연다(사용자 결정). 외부 본문 보호 중이거나 자리 값이 개인정보처럼 보이거나 완성한 주소에 결제·개인정보 단서가 있으면 카드로 묻는다. 연 사이트는 이 대화에서 사용자가 고른 사이트로 둔다(카드로 허락한 이동과 같은 범위)
  - 최대 20개, 넘으면 가장 오랫동안 쓰지 않은(마지막으로 연 시각) 링크를 지움(저장 카드에 미리 보임). 지난 형식(주소 하나)은 자리 없는 템플릿으로 옮김. 설정에서 이름·용도 고치기·지우기. 시크릿 창은 저장·후보 제공 없음
- **현재 시각** — 매 모델 요청 끝에 사용자 컴퓨터의 날짜·요일·시각(분 단위)·시간대 이름·UTC 오프셋을 "사용자 글 아님" 안내로 붙인다(대화 기록에는 넣지 않음). 모델이 지난 연도로 검색·예약하지 않게 하려는 것으로, 시간대(예: Asia/Seoul)가 OpenRouter와 모델 제공자에 전달된다
- **외부 본문 보호** — 파일 읽기(`read_document`)·첨부 파일 저장(`download_files`, 결과에 서버가 정한 파일 이름)·Google 도구·PDF 첨부처럼 외부 유래 데이터가 대화에 들어오면(성공·실패 모두) 그 대화에서는 페이지를 바꾸지 않는 관측 도구(`describe_page`·`get_page_content`·`list_page_images`·`list_file_links`·`query_dom`·`find_clickables`·`find_form_fields`) 외의 모든 도구를 자동 실행·링크 이동 허락과 관계없이 승인 카드로 물음(맡기기 방식으로 작업을 맡긴 동안은 제외, #123)(외부 내용을 신뢰 사이트의 검색어·입력값·번역 언어·Google 검색어로 내보내지 않게). "이번 대화 동안 묻지 않기"(#53)도 번역·이미지 저장에는 쓰지 않고, 페이지가 준 주소만 쿠키 없이 읽는 `read_linked_pages`에만 씀. 보호가 켜진 대화에서는 읽기 레시피를 저장하지 않음(보호 대상에서 유래한 인자가 새 대화로 넘어가지 않게). 이 기능 전에 저장된 레시피는 출처를 알 수 없어 새 저장소 세대로 바꾸며 지움(힌트로 쓰지 않음). 새 대화에서 해제. 도구 분류는 `src/lib/toolPolicy.ts`(모든 도구를 빠짐없이 분류해야 타입 검사 통과). 찾기·승인·실행 어디에서도 페이지에 대상 표시 속성을 쓰지 않음(id는 content script 메모리의 요소 → id 표로 관리)
- 모델 답변 속 이미지는 불러오지 않고 대체 글자와 주소만 보임(이미지 주소의 쿼리로 대화 내용이 승인 없이 새지 않게). 패널·설정 화면 CSP도 외부 이미지를 막음
- **자동 로그인** — KeePassXC와는 native messaging(`keepassxc-proxy`, 선택 권한 `nativeMessaging`)과 KeePassXC-Browser 프로토콜(세션마다 새 키, 응답 nonce 확인)로만 주고받고, 연결 승인·사이트별 접근 허락은 KeePassXC 창에서 사용자가 한다. 받은 값은 그 호출의 메모리에만 두고 결과·오류·로그에 싣지 않는다. 출처는 모델 인자가 아니라 브라우저가 아는 탭 주소로 정하고, 자동 실행은 그 출처에 묶은 항목이 KeePassXC 응답에 있을 때만 한다. 승인한 사이트라도 https가 아님·다른 사이트에 끼워 넣은 칸·다른 출처로 보내는 양식·POST가 아닌 제출·새 비밀번호 칸·삭제·결제 신호·외부 본문 보호 중·이 대화에서 이미 시도한 출처면 카드로 묻는다. 넣은 값(아이디 포함)은 브라우저를 끌 때까지 가림 목록(`chrome.storage.session`)에 두고, 도구 결과를 기록에 넣을 때와 모든 모델 요청(대화·번역·저장 링크 초안)에서 그 값과 흔한 표현(URL·폼 인코딩, HTML 엔티티, base64, JSON 이스케이프, 공백 정리, 잘린 앞·뒷부분)을 `[가린 값]`으로 바꾼다(페이지 스크립트가 값을 바꿔 쓰는 것까지는 막지 못함 — 페이지 자체는 넣은 값을 읽을 수 있으니 믿는 사이트만 승인)
- **실행 방식** (#123) — 페이지를 바꾸는 동작을 언제 묻는지 셋 중에 고름(입력창 아래·설정 → 동작)
  - 모든 동작에 승인 후 실행(기본): 이동·클릭·입력·저장마다 승인 카드
  - 페이지 이동·클릭·입력을 묻지 않고 실행: 결제·개인정보 제출·삭제·스팸·다른 사이트 이동처럼 위험한 동작만 승인 카드
  - 처음에 승인 받고 끝까지 실행: 작업 맡기기 카드로 한 번 묻고, 맡기면 그 대화가 끝날 때까지 결제·삭제와 외부 본문 보호를 포함해 묻지 않음. 직접 조작할 사이트의 손 넘기기, 자동 로그인 항목 고르기, 다른 탭 고르기는 그대로 사용자가 함
- 다운로드·탐색 URL은 `http(s):`만 허용, `javascript:` / 제어문자 차단

# 간편 브라우저 도우미 (Simple Browser Plugin)

Chrome 사이드 패널에서 말로 시키는 브라우저 도우미입니다. 지금 보는 페이지를 읽고 요약·번역하며, 입력칸을 채우고 버튼을 누르고, 파일을 읽거나 저장하는 일을 대신합니다.
AI 모델은 직접 고릅니다: OpenRouter(여러 회사 모델), OpenAI, Google Gemini, Anthropic Claude.

**[최신 버전 받기](https://github.com/ingki3/simple-browser-plugin/releases/latest)** · [설치 안내](docs/install.md) · [English](README.en.md) · Chrome 116 이상 · MIT 라이선스

> 안정 버전은 Releases(main 브랜치)입니다. 저장소의 기본 브랜치 `dev`는 개발 중인 코드입니다.
> 화면은 한국어만 지원합니다.

## 무엇을 할 수 있나요

| 하고 싶은 일 | 이렇게 말해 보세요 |
|---|---|
| 읽기·요약 | "이 페이지 세 줄로 요약해 줘", "가격 얘기는 몇 분쯤 나와?"(YouTube) |
| 번역 | "이 페이지 한국어로 번역해 줘" |
| 파일 읽기 | "이 논문 요약해 줘"(PDF 탭), "이 공고의 첨부 한글 파일 요약해 줘", "이 페이지의 엑셀 파일 정리해 줘" |
| 입력·클릭·이동 | "빈 입력칸 채워 줘. 이름: 홍길동", "필터를 최신순으로 바꿔 줘", "배송 상황 확인해 줘" |
| 저장 | "상품 사진 3번째부터 5번째까지 저장해 줘", "첨부 파일 중 PDF만 받아 줘", "페이지 전체 캡처해 줘" |
| 반복 확인 | "10분마다 이 페이지 확인해서 예매가 열리면 R석 2장 예약해 줘" — 등록 카드에서 승인하면 정한 간격으로 확인하고, 조건이 맞으면 알려 줍니다. 예약은 "이어서 진행"을 누르면 시작합니다 |
| 텔레그램으로 시키기 | 설정에서 텔레그램 봇을 연결하면 휴대폰에서 "naver.com에서 오늘 날씨 알려 줘"처럼 보내고 답을 텔레그램으로 받습니다. 결제·로그인처럼 승인이 필요한 동작은 하지 않습니다 |
| 다시 쓰기 | 자주 쓰는 검색 페이지를 "이 페이지 기억하기"로 저장해 두면, 다음에 "맥북 최저가 찾아 줘"처럼 말할 때 그 링크로 엽니다 |

선택 기능
- **자동 로그인**: KeePassXC에 저장한 계정으로 로그인합니다. KeePassXC가 필요합니다.
- **Google 시트·문서·드라이브**: 직접 빌드해야 씁니다. [설치 안내](docs/install.md#google-연동선택-직접-빌드-필요)를 보세요.

## 설치

1. [Releases](https://github.com/ingki3/simple-browser-plugin/releases/latest)에서 `simple-browser-plugin-vX.X.XX.zip`을 받아 풉니다.
2. `chrome://extensions`에서 **개발자 모드**를 켜고, **압축해제된 확장 프로그램 로드**로 푼 폴더를 고릅니다.
3. 도구 모음의 퍼즐 조각 버튼에서 **간편 브라우저 도우미**를 고정하고, 아이콘을 눌러 사이드 패널을 엽니다.

업데이트, 설치 때 뜨는 권한의 뜻, 직접 빌드는 [설치 안내](docs/install.md)에 있습니다.

## 처음 쓰기

1. 패널을 처음 열면 API 키 안내가 보입니다. 아래 표에서 서비스 하나를 골라 키를 받습니다.
2. **설정 열기** → 모델 제공자를 고르고 키를 넣은 뒤 **저장**을 누릅니다.
3. **연결 확인**을 누르면 짧은 요청 한 번으로 키와 모델이 되는지 확인합니다.
4. 아무 웹 페이지를 열고 "이 페이지 세 줄로 요약해 줘"를 보내 봅니다.

모델은 잘 모르면 기본값을 쓰세요. 직접 고를 때는 도구 호출(tool calling)을 지원하는 모델이어야 합니다.

## API 키와 비용

이 확장 자체는 무료이고, AI 모델을 쓴 만큼 고른 서비스에 요금을 냅니다. ChatGPT·Gemini·Claude 앱의 월 구독과는 따로입니다.

| 서비스 | 키 발급 | 요금 | 사용량 |
|---|---|---|---|
| OpenRouter (처음이라면 권장, 키 하나로 여러 회사 모델) | [openrouter.ai/keys](https://openrouter.ai/keys) | [모델별 요금](https://openrouter.ai/models) | [Activity](https://openrouter.ai/activity) |
| OpenAI | [API keys](https://platform.openai.com/api-keys) | [Pricing](https://openai.com/api/pricing/) | [Usage](https://platform.openai.com/usage) |
| Google Gemini | [AI Studio](https://aistudio.google.com/apikey) | [Pricing](https://ai.google.dev/gemini-api/docs/pricing) | [AI Studio](https://aistudio.google.com/) |
| Anthropic Claude | [Console](https://console.anthropic.com/settings/keys) | [Pricing](https://www.anthropic.com/pricing#api) | [Usage](https://console.anthropic.com/usage) |

- 요금은 보낸 글자(대화, 페이지 내용)와 받은 답의 양으로 정해집니다. 긴 페이지를 읽거나 단계가 많은 작업일수록 많이 듭니다.
- 키를 받은 곳에서 **사용 한도**를 정해 두면 예상보다 많이 쓰는 일을 막을 수 있습니다.
- 키는 이 브라우저(`chrome.storage.local`)에만 저장되고, 고른 서비스를 부를 때만 씁니다. 암호화하지 않으니 공용 컴퓨터에서는 쓰지 마세요.

## 실행 방식

페이지를 바꾸는 동작(이동·클릭·입력·저장)을 언제 물을지 입력창 아래에서 고릅니다.

| 실행 방식 | 동작 |
|---|---|
| 모든 동작에 승인 후 실행 (기본) | 동작마다 무엇을 할지 카드로 보여 주고, 승인해야 실행합니다 |
| 페이지 이동·클릭·입력을 묻지 않고 실행 | 대부분 바로 실행합니다. 결제, 개인정보 제출, 삭제, 다른 사이트로 이동처럼 위험한 동작은 계속 묻습니다 |
| 처음에 승인 받고 끝까지 실행 | 처음에 할 일과 위험을 한 번 보여 주고, 맡기면 그 대화가 끝날 때까지 **결제·삭제를 포함해** 묻지 않습니다. 믿을 수 있는 일과 사이트에서만 쓰세요 |

자동화를 막는 사이트는 설정 → 동작 → **직접 조작할 사이트**에 넣으면, 도우미가 누를 곳을 표시하고 사용자가 직접 누릅니다.

## 개인정보와 안전

- **보내는 곳**: 대화와 페이지 내용은 설정에서 고른 AI 서비스 한 곳으로만 보냅니다. 이 프로젝트의 서버는 없습니다.
- **보내는 것**
  - 페이지의 화면 글자: 버튼 이름, 라벨, 본문 등
  - 요청에 필요한 파일: PDF 탭의 PDF 파일, 읽으라고 한 첨부 파일
  - 현재 날짜와 시간대
  - PDF 파일을 통째로 보낼 때는 화면에 알립니다.
- **보내지 않는 것**
  - 입력칸에 사용자가 쓴 값: 찾기·클릭 도구의 결과에 넣지 않습니다.
  - 자동 로그인의 아이디·비밀번호
  - API 키: 고른 서비스 말고는 어디로도 보내지 않습니다.
- **페이지 속 숨은 지시문**: 웹 페이지가 AI를 속이려는 글을 숨겨 둘 수 있습니다. 그래서 외부 파일을 읽은 대화에서는 페이지를 바꾸는 동작을 매번 묻습니다. 단, '처음에 승인 받고 끝까지 실행'으로 맡긴 동안은 묻지 않습니다.
- **이 브라우저에만 남는 것**: 설정, 저장한 링크, 동작 기록. 동작 기록에는 입력값과 페이지 내용을 남기지 않으며, 설정에서 끄거나 지울 수 있습니다.

자세한 규칙은 [보안·개인정보 상세](docs/security.md)에 있습니다.

## 문제 해결

| 증상 | 해 볼 것 |
|---|---|
| "API 키가 맞지 않거나…" | 설정에서 키를 다시 붙여 넣고 저장한 뒤 **연결 확인** |
| "잔액이 부족합니다", "사용 한도에 닿았습니다" | 키를 받은 곳에서 충전하거나 한도를 확인 |
| 페이지를 읽지 못함, 응답이 없음 | 그 페이지를 새로고침합니다. 확장을 설치하거나 업데이트하기 전에 열려 있던 페이지는 새로고침해야 합니다 |
| `chrome://` 페이지, Chrome 웹 스토어 | Chrome이 확장의 접근을 막는 페이지라 읽을 수 없습니다 |
| 버튼을 눌러도 사이트가 반응하지 않음 | 설정 → 동작 → **실제 마우스 입력으로 클릭**을 켜거나, 그 사이트를 **직접 조작할 사이트**에 넣습니다 |
| 다른 PDF 뷰어 확장을 쓰는 중 | 주소가 `chrome-extension://`으로 바뀌어 읽지 못합니다. Chrome 기본 PDF 뷰어로 엽니다 |
| 그 밖의 문제 | 🐞(문제 신고용 진단) → **진단 복사**로 기록을 복사해 [이슈](https://github.com/ingki3/simple-browser-plugin/issues/new/choose)에 붙여 주세요. 방문한 주소가 들어 있을 수 있으니 확인한 뒤 올립니다 |
